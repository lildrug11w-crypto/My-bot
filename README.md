# 🤖 BiteByDay Developer AI

Telegram-бот для помощи с разработкой.

## Возможности

### 🎮 Roblox Studio

Помощь с:

- Luau / Lua
- Roblox Studio
- GUI
- RemoteEvent
- RemoteFunction
- ServerScriptService
- StarterPlayer
- ReplicatedStorage
- ошибками Output
- игровыми механиками
- исправлением скриптов

Используется модель:

`poolside/laguna-xs-2.1:free`

### 🛠 SA-MP / CRMP

Помощь с:

- Pawn
- SA-MP
- CRMP
- ошибками компиляции
- server_log
- серверными системами
- исправлением кода
